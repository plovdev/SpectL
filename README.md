# SpectL

SpectL - это программа которая управляет яркостью клавиатуры MacBook в такт музыке.

Отлично работает с macos 10.15 и мб выше.

## Сборка:

`mvn clean package`
KeyLight можно скачать из моего профиля GH.

### Важно

Используйте java 25+

## Запуск

`java --enable-native-access=ALL-UNNAMED -jar SpectL.jar`

Обязательно настройте BlackHole и поставьте его как дефолт, иначе ничего работать не будет.

Сделано для демонстрации возможностей AudioSND(хотя для fft анализа использовался JTransforms, движок используется для
чтения системного звука через BlackHole)
